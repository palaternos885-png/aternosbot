# بات ماینکرفت Yuta (AFK Bot)

بات با `mineflayer` ساخته شده، وارد سرور می‌شود، `/register` و `/login` را می‌فرستد و هر چند دقیقه یک‌بار در شعاع ۱۰ بلاک قدم می‌زند.

## ⚠️ نکات مهم قبل از استفاده
- استفاده از بات‌های ضد-ایدل برای زنده نگه‌داشتن مصنوعی سرور، در قوانین آترنوس ممنوع اعلام شده و ریسک مسدود شدن سرور را دارد.
- این بات فقط می‌تواند سروری را که از قبل روشن است زنده نگه دارد؛ اگر سرور آترنوس کاملاً خاموش باشد باید از پنل آترنوس روشن شود.
- اگر سرور شما در حالت آنلاین-مود (Online Mode) نیست (اکثر سرورهای آترنوس آفلاین‌مود هستند)، تنظیمات پیش‌فرض این کد درست است.

## مراحل راه‌اندازی

### ۱. آپلود روی GitHub
سه فایل `index.js`، `package.json` و این `README.md` را در یک ریپازیتوری جدید در گیت‌هاب قرار دهید.

### ۲. دیپلوی روی Railway
1. وارد Railway شوید → **New Project** → **Deploy from GitHub repo** → ریپازیتوری بالا را انتخاب کنید.
2. Railway به‌طور خودکار Node.js را تشخیص داده و `npm install && npm start` را اجرا می‌کند.
3. به بخش **Variables** بروید و متغیرهای زیر را اضافه کنید:

| نام متغیر | مقدار نمونه | توضیح |
|---|---|---|
| `SERVER_HOST` | `yourserver.aternos.me` | آدرس سرور آترنوس شما |
| `SERVER_PORT` | `25565` | پورت سرور (معمولاً همین) |
| `BOT_USERNAME` | `Yuta` | نام بات |
| `BOT_PASSWORD` | `13501350` | رمز برای register/login |
| `MC_VERSION` | `1.21.1` | نسخه ماینکرفت |
| `WALK_RADIUS` | `10` | شعاع راه رفتن (بلاک) |
| `WALK_INTERVAL_MINUTES` | `5` | فاصله زمانی بین هر حرکت (دقیقه) |

4. بعد از افزودن متغیرها، Railway به‌طور خودکار سرویس را ریستارت و اجرا می‌کند.

### ۳. بررسی لاگ‌ها
در تب **Deployments → View Logs** روی Railway می‌توانید ببینید که بات وصل شده، register/login انجام داده و در حال حرکت است.

## سفارشی‌سازی
- برای تغییر منطق ثبت‌نام/ورود (مثلاً اگر پلاگین AuthMe پیام متفاوتی می‌فرستد)، بخش `bot.on('message', ...)` در `index.js` را می‌توانید گسترش دهید تا بر اساس پیام سرور، دستور مناسب را بفرستد.
- اگر سرور شما آنلاین-مود (Premium/Online Mode) است، خط `auth: 'offline'` را از `index.js` حذف کنید (و به یک اکانت مایکروسافت واقعی نیاز دارید).
